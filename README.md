# 家電量販店7社 業績比較ダッシュボード

家電量販店主要7社（ヤマダHD・ケーズHD・エディオン・上新電機・ノジマ・ビックカメラ・コジマ）の
業績データを、各社公式IR決算短信・決算説明会資料から抽出・正規化したダッシュボード。
通期のほか、1Q/2Q単独/上期/3Q単独/3Q累計/4Q単独/下期の各期タブと、
8月決算2社（ビックカメラ・コジマ）を3月決算社の期間に揃えた「組替」データセット
トグルを備える。

## 公開ページ

GitHub Pages: `https://matsuno-delgit.github.io/kaden-retail-7co-fy2026/`

## 構成

```
.
├── index.html                       # ダッシュボード本体（単一HTML, Chart.js + 自己ホストTailwind）
├── assets/
│   └── tailwind.css                 # Tailwind 利用クラス抽出版（自己ホスト）
├── data/
│   ├── companies.json               # 通期（実績+前々期+計画）
│   ├── companies_{q1,q2,h1,q3,q3cum,q4,h2}.json      # 四半期・上下期 各タブ
│   └── companies_kumikae_{fy,q1,q2,h1,q3,q3cum,q4,h2}.json  # 組替（期間揃え）
├── scripts/
│   ├── consolidate.py               # 通期実績Excel → companies.json
│   ├── consolidate_q1.py            # 1Q Excel → companies_q1.json
│   ├── consolidate_quarter.py       # 2Q/上期/3Q/3Q累計/4Q/下期 → companies_*.json
│   ├── consolidate_kumikae.py       # 期間揃え比較Excel → companies_kumikae_*.json
│   ├── xlsx_utils.py                # 共通: 最新ver自動検出・データシート特定
│   └── regenerate-tailwind.md       # tailwind.css 再生成手順
├── SECURITY.md                      # セキュリティ方針
├── LICENSE                          # MIT
└── README.md
```

入力Excelは親フォルダ群（`01_通期実績_2026.03/` ほか）の**最新版（`_ver.N` 最大）を
自動検出**する。Excel更新時にスクリプトの書き換えは不要。

## データ検証ステータス

- 通期: 各社の主要20項目（売上高/営業利益/経常利益/純利益/総資産/自己資本 等）
  ×当期/前期=140セルすべて短信PDFと**完全一致**を確認済み
- 四半期・上下期・前々期・組替の各データセットも、PDF突合＋差引クロスフット＋
  組替整合検証（`00_共通スクリプト/verify_retro.py`、2026-07-12 実施）で全件一致を確認済み
- セグメント情報（デンキセグ・ノジマ家電専門店・ビック単体）も決算説明会資料と一致確認済
- 詳細はプロジェクトフォルダ内の「検証レポート_20260522.md」（GitHubには含まれない
  ローカル文書）および各期フォルダの `verify_*_out.txt` を参照

### 2026-08-02 更新分その2（推移グラフを全決算期の時系列に）

- **推移グラフの横軸を絶対表記に**。「前々期 / 前期 / 当期」をやめ、
  「2026年3月期 1Q」「2024年3月期 通期」のように決算期そのものを2行で表示する。
  軸は3月決算社の決算期で統一し、8月決算社の実期間はカードと詳細テーブルで補う。
- **表示できる全決算期を1本の時系列にする**。従来は選択年度が持つ3点だけを描いていたため、
  2024年3月期を選ぶとその先の実績が見えなかった。以後は同じデータセット・同じ期間種別で
  用意している全年度のJSONを読み、古い順に並べる（先頭に最古年度の前期を1点足す）。
  年度を切り替えても横軸は変わらず、選択位置だけが移動する。
  - 通常版 通期: 2023/3 → 2026/3 の4期 ＋ 2027/3計画
  - 通常版 1Q: 2023/3 → 2027/3 の5期
  - 組替版 通期: 2024/3 → 2026/3 の3期
- **選択中の決算期を薄い青の縦帯で示す**。全期間を並べると現在地が分からなくなるため。
- 会社計画の点は破線でつなぎ、ツールチップに「（会社計画）」と付す。
- **修正**: `consolidate_fy.py` が通期グラフ用の `asset_turnover` / `inventory_turnover` を
  null で初期化したまま埋めていなかった。2024年3月期・2025年3月期（通常版・組替版とも）の
  全社が空となり、通期の回転率グラフが最新1点しか描けていなかった。
- **通期の回転率グラフを2期平均ベースに統一**。従来は「当期売上 ÷ 期末残高」で、
  サマリーカードや四半期グラフの「直近12ヶ月売上 ÷ 2期平均残高」と同名なのに定義が違っていた
  （ヤマダHD 2026年3月期で 1.30回 vs 1.29回）。ROE・ROICと同じLTM基準に寄せた。
  デンキセグメントだけは連結BSから2期平均を組めないため会社開示値（年度指標）のまま。
- 各系列の最古年度はLTM指標（ROE・ROIC・回転率）が空になる。2期平均の分母に
  さらに1年前の同期末BSが要るため。埋めるには2022年3月期の期末BS抽出が必要。

### 2026-08-02 更新分（在庫回転率の追加・期間表記の明確化・年度の拡充）

- **デュポンROE表示に「在庫回転率（前期差）」を追加**。売上高の直下、区切り線の上に置き、
  在庫効率 → 収益性・回転・レバレッジ の順で読めるようにした。
  分子は直近12ヶ月売上高、分母は当期末・前年同期末の2期平均棚卸資産。
- **期間表記を各社の実期間に統一**。従来は組替版でビック・コジマも「2026年08月期」と
  だけ表示され、どの期間の実績か読み取れなかった。以後は自社の四半期と1対1で対応する
  期間は「2025年08月期 3Q単独」、会計年度をまたぐ期間（組替通期・組替3Q累計）は
  「2025年3月〜2026年2月」のように暦月で明示する。通常版も同じ規則で表示する。
- **通常版の2027年3月期を新設**（`20_1Q実績_2027.03_通常版`）。3月決算社の1Q（2026/4-6）に
  ビック・コジマの2026年8月期1Q（2025/9-11）を四半期番号どうしで対応させたもの。
  暦月で揃える組替版（`19_1Q実績_2027.03`）と選択して比較できる。
- **通常版の2025年3月期を新設**（`21_`〜`28_` の8期間）。当期列＝2026系列の前期列、
  前期列＝2024系列の当期列で組み直したもので、新規のPDF抽出は行っていない。
- **2027年3月期のLTM指標（在庫回転率・総資産回転率・ROE・ROIC）を算定**。
  1Q時点のLTM＝当期1Q＋前期2Q〜4Q。開示済みのノジマ・ビック・コジマに値が入る。
- **ROICの算定条件を訂正**。投下資本＝有利子負債＋自己資本のところ、四半期末の自己資本を
  未抽出の期で分母が有利子負債だけになり、ROICが過大に出ていた（全ブック計208セル）。
  自己資本が揃っている列のみ算定するよう改め、該当セルは空欄化した。
- データセット × 年度の可否
  | | 2027/3 | 2026/3 | 2025/3 | 2024/3 |
  |---|---|---|---|---|
  | 組替版 | 1Qのみ | 8期間 | 8期間 | — |
  | 通常版 | 1Qのみ | 8期間 | 8期間 | 8期間 |
- 2025年3月期・2024年3月期の四半期は、当時の短信で四半期末の自己資本を採録していないため
  ROE・ROICが空欄になる（通期は算定可）。

### 2026-07-31 更新分その2（組替版を既定化・サマリー圧縮）

- **既定を組替版に変更**。データセット選択の並びも「組替版 → 通常版」に入れ替えた。
  決算月の違う8月決算社を暦月で3月決算社に合わせた方が同じ市況を比べられるため。
  通常版（四半期番号どうしの比較）は選択式で残している。
- **組替版で2025年3月期を選択可能に**。期間揃え比較 09_〜16_ の当期列が
  「2024年3月〜2025年2月」＝3月決算社のFY2025にあたるため、そのまま年度として出せる。
- データセット × 年度の可否
  | | 2027/3 | 2026/3 | 2025/3 | 2024/3 |
  |---|---|---|---|---|
  | 組替版 | 1Qのみ | 8期間 | 8期間 | — |
  | 通常版 | — | 8期間 | — | 8期間 |
- **7社サマリーを圧縮**。「経常利益（率）」「純利益（率）」のように金額と率を1行にまとめ、
  その下に「YoY（前期差）」を置く形に変更。縦の情報量を減らし横スペースを活用する。
- **デュポンROE表示時は売上総利益率・経常利益率・純利益を畳む**。代わりに
  純利益率・総資産回転率・財務レバレッジ・ROEの4項目に前期差を併記する。

## データ更新手順

```bash
# 1. 新しい四半期/通期PDFをエビデンスフォルダに配置
# 2. extract系スクリプトで抽出・verify系スクリプトで検証（親フォルダ側の作業）
# 3. Excel を新しい _ver.N+1 として保存（スクリプトは最新verを自動検出）
# 4. consolidate 4本で data/*.json を再生成
cd kaden-retail-7co-fy2026
uv run --no-project python scripts/consolidate.py
uv run --no-project python scripts/consolidate_q1.py
uv run --no-project python scripts/consolidate_quarter.py
uv run --no-project python scripts/consolidate_kumikae.py
git diff data/          # 差分がデータとして妥当か確認
git add data/
git commit -m "Update <FY/期>"
git push
```

push後、GitHub Pages が1〜2分で自動再ビルドされ反映されます。
